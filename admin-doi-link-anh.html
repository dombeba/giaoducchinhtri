🔗 Admin — Đổi link ảnh (Google Drive → Web)

Dán link Drive → tự tách ID → xuất ra link ảnh chuẩn (UC + Thumbnail) để dán lên web.

🛠 Admin Tin tức 📰 Trang tin 🏠 Trang chủ

1) Dán link Google Drive

2) Kết quả link ảnh dùng cho web

✅ Link UC (chuẩn, ổn định)
🖼 Link Thumbnail (hợp ảnh bài viết)
📌 Gợi ý dùng nhanh
  • Ảnh đại diện / ảnh đầu bài: thường dùng Thumbnail.
  • Chèn ảnh giữa bài: dùng UC cho ổn định.
  • Nếu web không hiện ảnh: vào Drive → Chia sẻ → “Bất kỳ ai có liên kết” (Viewer).

3) Kiểm tra nhanh (tự động)

Sau khi đổi link, bấm mở thử 1 link UC/Thumbnail trong tab mới: nếu hiện ảnh trực tiếp là OK.
